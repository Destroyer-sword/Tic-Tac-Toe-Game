# ❌⭕ Tic Tac Toe Game

[![Netlify Status](https://api.netlify.com/api/v1/badges/site-status/deploy-status)](https://tticttacttoegame.netlify.app/)

A classic, browser-based **Tic Tac Toe** (Noughts and Crosses) game featuring a clean user interface, win-detection logic, draw detection, and instant game reset functionality.

---

## 🚀 Live Demo

Play the game live in your browser:  
👉 **[Tic Tac Toe Game Live Preview](https://tticttacttoegame.netlify.app/)**

---

## ✨ Features

- **2-Player Gameplay:** Take turns playing locally as **X** and **O**.
- **Automatic Win Detection:** Evaluates winning combinations across rows, columns, and diagonals in real time.
- **Draw Detection:** Detects when all grid cells are filled without a winner.
- **Game Reset / New Game:** Clear the grid and reset game states with a single click.
- **Responsive Grid UI:** Clean, centered grid layout optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Built With

- **HTML5:** Semantic grid structure and UI containers.
- **CSS3:** Styling, grid layouts, turn indicators, and interactive hover effects.
- **JavaScript (ES6):** Game state management, win pattern algorithms, and event handling.
- **Netlify:** Continuous deployment and web hosting.
